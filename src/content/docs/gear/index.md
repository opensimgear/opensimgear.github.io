OpenSimGear is developing open-source controls for sim racing and flight simulation. This section brings together the
current system architecture for the project's own gear.

Start with the [modular peripheral architecture](/gear/architecture/) to understand how individual controls work as
standalone USB HID devices and connect through a CAN gateway. The architecture pages cover hardware, communication, USB
behavior, the desktop cockpit, repositories, and recorded validation boundaries.

The designs are under development. Use the [implementation baseline](/gear/architecture/decisions/) to understand the
current prototype scope before starting a build. Implementation and qualification work is tracked in the
[GitHub project](https://github.com/orgs/opensimgear/projects/2).

For general equipment guidance, explore the [component guides](/docs/components/) and [DIY guides](/docs/diy/).
