## Intro

OpenSimGear develops sim racing and flight simulation hardware, firmware, software and technical documentation.
The project explores modular controls, shared connections and tools for configuring simulator equipment.

The public website and repositories describe the architecture and current prototypes. Public visibility does not
provide an open-source license or permission to reuse the material.

## Current licensing status

Licensing is under review. First-party OpenSimGear code, hardware designs and documentation are currently **all rights
reserved**. No general license is offered for personal, noncommercial or commercial use. Applicable law, GitHub platform
rights, third-party licenses and separate written permissions remain applicable.

Read [licensing and permissions](/policies/licensing/) before reusing material, building from project designs or making
commercial plans. External creative contributions are paused; the [contribution policy](/contributing/) explains the
current position. Questions and factual bug reports remain possible.
